# WiFly485 Web管理界面使用指南

## 简介

WiFly485 Web管理界面提供了一个基于浏览器的用户界面，用于配置和监控WiFly485设备。该界面支持主设备和从设备，具有响应式设计，可在各种设备上使用。

## 访问Web管理界面

1. 确保WiFly485设备已连接到网络
2. 打开Web浏览器
3. 在地址栏中输入设备的IP地址
4. 按回车键访问Web管理界面

## 主要功能

### 1. 设备状态监控
- 设备角色（主设备/从设备）
- 设备名称
- WiFi连接状态
- IP地址
- 设备运行时间

### 2. 配置管理
- 网络配置（SSID、密码、IP设置等）
- RS485通信参数（波特率、数据位、校验位、停止位）
- 设备配置（设备名称、角色、端口设置）

### 3. 系统控制
- 重启设备
- 配置管理

## 页面说明

### 主页面
主页面显示设备的基本状态信息，包括设备角色、名称、WiFi状态、IP地址和运行时间。

### 配置页面
配置页面允许用户修改设备的各种配置参数：
- 网络配置部分：设置WiFi连接参数
- RS485配置部分：设置RS485通信参数
- 设备配置部分：设置设备基本信息和端口

## API接口

Web管理界面提供RESTful API接口，可用于程序化访问设备配置和状态：

### 获取设备状态
- URL: `/api/status`
- 方法: GET
- 响应: JSON格式的设备状态信息

### 获取配置
- URL: `/api/config`
- 方法: GET
- 响应: JSON格式的设备配置信息

### 设置配置
- URL: `/api/config`
- 方法: POST
- 请求: JSON格式的配置数据
- 响应: 操作结果

## 安全注意事项

1. Web管理界面未实现用户认证，请在受信任的网络环境中使用
2. 修改配置后需要重启设备才能生效
3. 请勿在生产环境中随意修改配置参数

## 故障排除

### 无法访问Web界面
1. 检查设备是否已连接到网络
2. 确认输入的IP地址是否正确
3. 检查设备是否正常运行

### 配置保存失败
1. 检查网络连接是否稳定
2. 确认配置参数是否符合要求
3. 重启设备后再次尝试

## 技术细节

### 文件结构
Web界面文件存储在设备的SPIFFS文件系统中：
- `index.html` - 主页面
- `config.html` - 配置页面
- `style.css` - 样式文件
- `script.js` - JavaScript脚本

### 响应式设计
Web界面采用响应式设计，适配各种屏幕尺寸：
- 桌面浏览器
- 平板设备
- 手机设备

### 浏览器兼容性
Web界面支持以下浏览器：
- Chrome 50+
- Firefox 50+
- Safari 10+
- Edge 15+
